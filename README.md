# 🌿 BergenpuffStoreBot

A polished, production-ready Telegram navigation bot for Bergenpuff Store.

Users tap inline buttons to open official Telegram destinations — the raw
URLs are **never displayed as text**.

Bot: [@BergenpuffStoreBot](https://t.me/BergenpuffStoreBot)

---

## ✨ Features

- 🌿 Clean, modern, mobile-first Telegram interface
- 📢 Channel and 💬 Community Group buttons (URLs hidden behind buttons)
- ℹ️ About page, 📞 Contact page
- ⚙️ Full admin panel: add, edit, enable/disable, reorder, delete destinations
- 📊 Click analytics: total users, total clicks, today / week / month, top destinations
- 🔐 Admin access limited to configured Telegram IDs
- 🔗 Deep links: `/start channel`, `/start group`
- 🗄 SQLite + SQLAlchemy (auto-initialized on first run)
- 🚀 Ready for Railway deployment (polling)
